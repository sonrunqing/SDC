# 0.4.7 手机专用输入、物品详情与弹挂

日期：2026-10-18。合并本次三个用户请求，Android 固定包名和签名继续沿用。

## 手机输入

- 删除世界中的 WASD、键盘快捷键、鼠标瞄准和开火，以及各预览、仓库、按钮、滚动、布局画布中的鼠标分支。
- 关闭 `pointing/emulate_mouse_from_touch` 和 `pointing/emulate_touch_from_mouse`。游戏输入直接处理 `ScreenTouch/ScreenDrag`。
- 移动、旋转和开火分别拥有触点。`set_aim(Vector2)` 不写开火状态，只有 `set_fire(bool)` 控制按住开火。
- 设置和筛选使用触摸大行选择列表，音量/亮度等滑条支持横滑调值、纵滑滚动，开关在有效松手时切换。数量使用大号加减按钮和手机数字输入法。
- 搜索和数字输入通过 `LineEdit.edit()` 打开手机输入法，保留 IME 文本接收；无键盘游玩快捷键。实现参照 [Godot LineEdit 的编辑与软键盘接口](https://docs.godotengine.org/en/4.6/classes/class_lineedit.html#class-lineedit-method-edit)。
- Android 返回先关闭选择列表，再关闭布局编辑草稿或按当前页面返回。弹层打开时立即取消此前触点，关闭后旧触点释放也不能激活底层控件。
- 应用后台、失焦、场景暂停、控件隐藏时清理手势。`mouse_filter` 仅保留为 Godot 的 GUI 触摸路由属性。

## 全物品详情

仓库单次点选即可查看详情，内嵌区域固定预留空间；点选不会挤走原位置的物品，仍可继续点击放置、双击快捷转移或长按拖动。只有用户主动收起/展开时改变详情区大小。正文独立滚动，拖动时保留区域空间并显示简短提示。

详情从 Catalog、实际装备配件和 InventoryGrid 的权威几何生成，覆盖全部 **260** 件物品：

| 类型 | 数量 | 详情 |
| --- | ---: | --- |
| 枪械 | 24 | 原有说明、口径、七项性能、弹容量、消音、初速、安装接口与兼容弹药；已装备枪械使用当前配件配置 |
| 配件 | 145 | 原有说明、类别用途、实际增益、接口、兼容枪械/口径，供弹组件显示装上后的弹容量 |
| 弹药 | 36 | 口径、弹种、穿透、伤害及弹道系数、兼容枪械、堆叠 |

## 普通弹挂与防弹弹挂

- 原 4 款物品 ID 不变，类别改为 `rig`：紧凑、巡逻、行动、装载弹挂，各 8/12/18/24 格。移除所有防弹属性，仅提供收纳，可与防弹衣和背包同穿。
- 新增独立商店组“防弹弹挂”，4 件新物品 `armored_rig_guard_scout/patrol/operator/cargo`，类别 `armored_rig`。分别为 1–4 级、13/26/39/52 防护、8/12/18/24 格，价格及重量含护甲部分。
- 防弹弹挂替代防弹衣，可与背包同穿。防弹衣栏以 0.38 透明度映射真实弹挂 UID；不存在第二件实物，不重复计数或计重。影子位置仍可作为防弹衣替换目标。
- `Catalog.equipment_slot()` 将两类物品映射到历史后端 `armored_rig` 槽，`is_armored_rig()` 只识别真正的防弹结合体。旧普通弹挂 ID、保存路径和 schema 3 保持兼容。
- 拖动、单击放置、双击和普通装备入口共用映射；换装和容器缩小沿用完整快照、内容物归位及溢出回滚。
- 新物品通过 `visual_alias` 复用现有弹挂模型与图标，人物上的防弹结合体增加独立胸板标识。已有模型未重新生成；视觉生成器已支持普通弹挂的布面和弹袋。
