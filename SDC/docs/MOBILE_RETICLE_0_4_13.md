# 0.4.13：手机十字准星与物品分层

## 十字准星

参考旧项目 `Ashfront/scripts/Ui/Crosshair.cs` 的四臂短线和中心点，新增 `ui_aim_reticle.gd`。旧项目读取鼠标坐标；本版仅消费 SDC 已有右下瞄准摇杆产生的世界朝向，没有增加键盘、鼠标、触摸转鼠标或任何准星输入处理。

- 右摇杆改变人物朝向；拨动幅度也控制准星参考距离。松手保持最后朝向和参考距离。
- 参考点沿实际人物朝向放在胸口高度的射线上，与开火使用同样的防穿墙起点。每个物理帧至多增加一次射线查询；碰到场景或人物碰撞体就截断。
- 参考点按屏幕安全范围缩短世界距离，不能通过把屏幕坐标横竖硬钳制而改变指向。准星不是射程终点，也不保证有散布的每发子弹都落在中心；原有弹道、辅助瞄准与霰弹逻辑沿用。
- 实际枪口附近绘制一段短方向提示，准星采用浅色线和暗描边，移动与后坐散布影响张开程度。未增加待机闪烁或呼吸动画。
- 准星作为 `raid_presentation` 的独立子 CanvasItem，位于视野暗化层之上、手机 HUD 之下；自身忽略输入。搜索、暂停、设置等阻断战局输入时隐藏，结束战局不保留显示。

移动、瞄准、开火原有独立触点归属与释放代码未修改。`_base_shot_spread()` 只抽取原开火公式供显示复用，原散布计算和弹药消耗条件保持一致。

## 清晰底色与图标独立绘制

0.4.12 的低饱和品质色与深底透明混合形成灰蒙观感；原图标已在背景之后画，并不是一个额外的全屏灰雾覆盖图标。本版按反馈改为直接配出的实色品质背景，取代继续增加半透明罩层。

已发现品质色仍为灰、绿、蓝、黄、红。底色定义在 `item_rarity.gd` 的 `BACKGROUNDS`，边框继续使用原有 `TONES`，图标使用原始纹理和白色调制。

`ui_inventory_grid.gd` 分为三个按树顺序绘制的 CanvasItem：

1. 网格父层：空格、未知搜索效果、已发现品质底色与边框。
2. `ItemIcons`：图标、名称和数量，只在图标发现动画及装备淡色别名时改变自身透明度，不继承品质颜色。
3. `InteractionOverlays`：开盖遮片与拖动目标提示，盖住图标时仅表示当前交互。

未设置更高的全局 `z_index`，以免图标越过滚动裁剪或后打开的模态界面。背景与图标两个分支都先检查未知 UID，再读取 Catalog 或加载纹理，因此未搜索物品仍没有品质色或物品信息。格子几何、命中判断、拖放、UID、数量和装备事务不作本次变更。

## 本轮产物

实际使用 Godot 4.6.3/OpenGL 渲染生产战局和品质格子，输出 `SDC-v0.4.13-aim.png`、`SDC-v0.4.13-rarity.png` 以及完整物资/搜索画面。图像在项目外的交付预览目录，渲染工具从 Android 包排除。

Android 构建身份与资源记录见仓库根 `development/android-v0.4.13.json`。本轮没有新增或运行自动测试，没有实际手机运行、帧率或覆盖安装结果。GitHub 静态审查与本机渲染不等于真机验收。
