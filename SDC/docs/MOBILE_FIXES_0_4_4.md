# 0.4.4 手机交互修复

日期：2026-10-17。

## 行动预览与出击

- 原底部“开始行动”总是调用 `_select_tab("maps")`。在预览页再次点击，只会拆掉并重建同一个地图预览，既不出击，也会造成短暂空白。现由 `_start_action()` 区分大厅导航和预览页出击：大厅打开地图，地图页调用 `_deploy()`。
- 出击开始即锁定重复提交并禁用按钮；装备/携弹校验失败则恢复按钮、显示原有错误原因并保留预览。
- 相同页面导航不再重建；地图页的状态更新只刷新必要信息，不销毁地图。
- 标题与地图尺寸合为一行，入口选择约 48 高，“全图”及区域按钮为 48 高，整备按钮为 52 高，侧栏间距缩小。区域列表保留至少 150 高并独立滚动。
- 地图、装备、设置页面采用受可用屏幕高度约束的内容区域，避免外层整页滚动再挤压内部列表。
- TouchButton 的最小触控高度改为可配置，地图紧凑按钮不再在 `_ready()` 时强制还原成 72 高。

## 地图手势

- 手机：单指上下左右平移；双指缩放、旋转及中心平移。
- 电脑：左键拖动平移、右键拖动旋转、滚轮缩放。
- 平移由相机射线与地面交点转换计算，在地图范围附近限制中心位置，避免视图无限拖离地图。
- 取消触摸或切出应用会清理手势状态，单指与双指切换时重置参考距离和角度。

## 按钮外观

- 清除主题中按钮、选择器、滑条、输入框等继承的焦点外框，取消橙色常驻光圈。
- 主行动按钮改为固定浅灰色，不再在黄色与青绿色间随触摸/悬停切换。
- 普通按钮正常和悬停配色相同，按下时只提供短暂明暗反馈；手指滑动取消点击后立即恢复。
- 选择物品时保留中性色边界与拖放有效位置反馈；导航与设置页签不再持续用金黄色着色。

## 背包与弹挂

用户补充现象为“装上后卸下去了”。发现原点击放置完成后，仍把目的装备格记录为双击的第一次点击；紧接着再点该格，会触发快捷卸下。

- 放置后直接结束当前点击链，不再为目的格继续累计双击。
- 双击快捷操作要求当前选中物品与两次点击的 UID 都相同；拖动、完成转移和装备区域重建会清空旧双击记录。
- 真正主动双击已装备物品，仍支持快捷卸回仓库。
- 弹挂与背包使用两个固定并排的装备格，不随流式排版换行挪位；数据层本来就是两个独立栏位，未增加二者互斥限制。防弹衣与弹挂甲的既有互斥规则保留。
