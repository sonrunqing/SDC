# 0.4.10 搜索手势与动画

用户要求搜索页采用仓库的直接交互，不提供“拿取所选”确认按钮。本版移除该按钮和目标下拉框；数量栏只控制接下来的转移数量，不增加一次确认操作。

| 操作 | 结果 |
| --- | --- |
| 快速双击容器已发现物品 | 自动寻找携行格子并拿取 |
| 快速双击携行物品 | 放回当前打开的容器 |
| 点击物品，再点击目标格子 | 放入目标区块或调整位置，自动适配横竖方向 |
| 长按或横向拖动物品 | 显示可放置位置，松手后转移 |
| 快速纵向滑动 | 滚动内容，不转移物品 |

点击、双击的 360 ms 窗口、300 ms 长按、12 px 滑动阈值与仓库一致。已选择的数量不会因开始拖动而重置。转移结束和取消手势后清除连续点击状态，后续点击先选择物品。未搜索物品不能拖动、合并、拿取或整理；对已发现物品的整理不会改变其他物品的发现进度。

放回容器先对有限格子做完整预排布，再从携行记录及对应的战利品、出战物品、备弹或医疗数量中扣除。容量不足两侧都不修改；不触及已装入枪械的弹药、局外仓库或穿戴栏。放回物品为已知物品，不需要重复搜索。已清空的箱子放入物品后可在本局重新打开。

搜索动画分为开箱遮片展开、未知物品扫描光带/旋转检索标记/百分比，以及发现后的短暂亮起、图标渐显和落位。增加总体进度条，按物品占格调整搜索时间；暂停时停止扫描动作。发现和完成搜索不触发转移。动画仅作用于搜索视图，按 30 Hz 请求动画重绘，拖动和数据更新继续各自响应；既有仓库格子不持续播放动画，按钮没有新增待机闪烁。

使用生产页面在 Godot 4.6.3 / OpenGL 下渲染 195 帧（6.5 秒）动画，并生成 PNG/GIF 预览。录制使用独立进度文件，冻结战局敌人，逐帧推进生产搜索流程；它是本机引擎画面，不是手机操作录屏。本轮没有新增或重跑自动测试，不将 0.4.9 的 93 项结果作为新版测试结果。安卓包、签名及版本信息以 `development/android-v0.4.10.json` 为准，真机手势和覆盖安装尚未验收。
