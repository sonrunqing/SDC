# 0.4.9 容器搜索与物资摆放

本次按用户描述的“打开容器、搜索、选择物品拿取、关闭容器”流程实现，不复制其他游戏资源。参考入口为[暗区突围官方教程](https://arenabreakout.com/tutorial/)；该站点需要 JavaScript，具体交互以用户的要求和本工程实现为准。

## 场景布置

`data/harbor_layout.json` 的 `loot_revision=3`。26 个固定搜索容器均在可进入建筑内：海关大厅 8 个、机修车间 5 个、调度办公室 5 个、装配车间 6 个、备件仓 2 个。容器沿墙或靠近货架，避开门口、室内通道、实体碰撞与封闭隔间。26 个容器均检查了从南港入口到可交互位置的导航路径和物理视线。

移除路边零散地面货箱，室外装饰货物集中为 6 组、18 只排列整齐的货箱。货架上的包裹继续保留；固定搜索容器不再摆在露天道路上。场景和选图共用布局。`scripts/loot_layout.py` 接入地图生成器，重新生成地图仍采用这套布置。

固定箱分为补给箱、工具箱、医疗箱、档案盒、电子器材箱与配件长箱，具有不同外观和物资池。附近并且可直接接触时显示名称与交互标记，墙后不能搜索。战斗掉落袋继续留在敌人倒地处；不会给导航突然增加不可通行障碍。

## 搜索页面

- 打开页面先播放开盖，再按稳定记录顺序逐件搜索。未完成的物品用未知格子和扫描线表示，不提前显示名称或图标。可暂停搜索。
- 左边显示真实口袋、分区弹挂、背包及负重，右边显示容器格子。只查看、搜索完成、关闭都不增加背包物品。
- 单击物品显示信息，选择数量后拿取；双击快捷拿取；按住或横向拖动物品放入左侧区块。也可选中后再点目标格子。纵向滑动用于滚动。区块内物品可调整位置，适配时智能旋转。
- 源物品有稳定 UID、数量、位置和发现状态。关闭后保留未拿物品和未完成搜索的进度；本局重开不刷新掉落。空箱不重复发放内容。
- 每次拿取先在携行记录副本上验证格子、重量和完整数量，再提交并扣除源箱数量。失败两边都保持原状。拾取弹药进入可使用备弹；不会同时当作另一份战利品计数。
- 开页立即取消旧触点，并阻止移动/开火。关闭、Android 返回、后台、离开交互范围、受伤和结算都清理页面及手势。敌人与行动计时继续运行；搜索不是暂停战局。

## 代码入口

| 文件 | 职责 |
| --- | --- |
| `loot_container_state.gd` | 稳定箱内记录、格子排布、开盖/逐件搜索进度 |
| `raid_world.gd` | 室内容器实体、物理视线、搜索生命周期与源物品扣除 |
| `ui_loot_search.gd` | 手机原始触摸搜索页面、数量、选择/双击/拖动 |
| `game_state.gd` | `receive_container_item` 原子接收与携行区移动 |
| `ui_inventory_grid.gd` | 复用已有物品格子，支持外部记录与未知物品绘制 |
| `main.gd` | 搜索页面与战局 HUD、独立触点、系统返回的连接 |
| `loot_layout.py` | 室内点位与整齐货物布置，供地图生成器复用 |

## 本机记录与边界

`test_container_search.gd` 本机通过 93 项：26 处导航与视线、未搜索不能拿、开页/搜索完成不发物资、暂停/关闭/重开状态、指定数量守恒、错误目标/超重失败回滚、竖向弹挂自动旋转、真实搜索页面触点归属、开页取消按住开火、Android 返回与旧触点释放、离开容器中断。相关整局和地图检查脚本同步更新了原有自动拾取断言；本轮未把未重新运行的历史检查计入通过数。

使用 Godot 4.6.3 / OpenGL 实际渲染搜索页（1280×720）与仓库揭顶场景（1600×900）。预览工具使用独立进度文件，不改用户存档。它们是本机引擎画面，不是真机截图。手机多指、滑动手感、帧率和覆盖安装仍需真实设备结果。

Android 0.4.9 / versionCode 16 已由项目外 `build-android.ps1` 导出，92,760,112 字节。与 0.4.8 核对为相同包名及固定证书，版本递增；APK 内确认包含新搜索脚本和 26 个室内点位，tools/tests/docs 未进入包。公开构建身份见 `development/android-v0.4.9.json`。

保存结构保持 schema 3；容器本局状态不写入长期仓库，退出未撤离战局仍遵循原有失败结算规则。APK、密钥及导入缓存不提交 Git。
