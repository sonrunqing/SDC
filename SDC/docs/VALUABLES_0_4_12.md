# 0.4.12：加深品质底色与同侧弹药整理

本版延续 [0.4.11 的 48 种变卖物、8 类与原创模型清单](VALUABLES_0_4_11.md)。

## 品质底色

按用户连续两次追加要求，已发现变卖物的品质底色透明度从 `0.14` 先调至 `0.224`（1.6 倍），再加深 2 倍到 `0.448`，即最初的 **3.2 倍**。五档色相仍为灰、绿、蓝、黄、红，图标与边框不作此次加深处理。实际显示仍受发现动画和装备淡色别名的透明度控制。

未搜索物品继续在品质读取前进入未知格子分支；未知底色、扫描和角标保持中性灰白，不随本次调整变色。

## 同侧弹药堆

处理 0.4.10 GitHub 静态审查中关于搜索页面同侧合堆的发现。选择后点击或拖到同一侧、已知的同类弹药堆时，先按所选数量和目标余量合并，余量留在来源堆；目标已满时明确返回失败。

点到空格时，全部数量移动保留原 UID，部分数量则分成新 UID 的独立堆。规划在副本完成，空间不足时原有数据保持不变。容器仍保持有限容量，未搜索记录不能参与合并；携行侧只改变格子分配，不调整备弹、战利品、医疗或负重总数。

箱内拆堆会增加一条已发现的物品堆，搜索页“已发现／总物品堆数”及总体进度的显示值会随之变化；未知物品的实际搜索计时和当前搜索目标不重置。合堆耗尽的来源保留零数量记录，避免删除记录导致搜索总数减少。

## 交付记录边界

实际品质对照画面来自 Godot 生产格子组件渲染。Android 版本、包名、固定证书、导出资源与哈希记录在 `development/android-v0.4.12.json`。本轮没有新增或运行自动测试，没有手机实际运行或覆盖安装结果；静态审查和本机资源渲染不代表真机验证。
