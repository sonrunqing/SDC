# 伤害与经济调参（0.2.2）

游戏中只显示 0–100 综合性能条。它归纳威力、精度、控制、操控、射程、射速和容量，方便比较改装方案；不是单发伤害、胜率或每秒伤害。实际伤害参数不在界面直接显示。

## 伤害

统一实现位于 `scripts/ballistics.gd`，通过 `Catalog.shot_profile()` / `shot_damage()` 调用。玩家射击和守卫射击均接入该模块，命中距离取自物理射线实际碰撞点。

伤害按以下顺序计算：

1. 枪械基础整发伤害 × 弹药微量威力系数 + 弹药额外伤害。
2. 乘以当前距离对应的伤害保留比例。
3. 根据弹药穿透和命中目标的护甲，计算实际减伤。

有效初速为枪械初速 × 弹药初速系数。初速提高会延后距离衰减，弹药阻力增大则提前衰减；配件的射程变化也参与有效距离。采用二次曲线：`保留比例 = 1 - ((距离 - 近距区间) / 曲线距离)²`。近距 2 米内保持全威力，之后每增加一米所损失的伤害随距离递增；伤害继续下降直到零，不设正数下限，超出后不产生负伤害。每发命中根据实际距离重新计算，与经过多少秒无关。

对芦苇 R9、普通弹和 22 防护守卫的参考组合，以正常跟随镜头的 21:9 手机最远可见边缘作为校准点：近距约 22.8，约 37.42 米的最远角落为 20.5。16:9 和 20:9 的视野较窄，屏幕内损失更小；这是固定世界距离曲线，切换屏幕比例不会改变同一世界距离的伤害。相机在地图边缘受限时人物不再处于正常跟随位置，可见距离也会变化。

| 参考距离（米） | 实际伤害（相同枪弹与护甲） |
| --- | ---: |
| 0 | 22.80 |
| 10 | 22.68 |
| 20 | 22.21 |
| 30 | 21.36 |
| 37.42（校准视野最远角落） | 20.50 |
| 50 | 18.58 |
| 80 | 11.64 |
| 100 | 5.19 |

这条曲线在屏幕内缓慢下降，屏幕以外持续加快下降；18.2 和 20.5 均不是伤害下限。枪种的曲线距离各不相同，霰弹枪偏近战，精确步枪能在更远距离保持威力。长距离枪械额外验证 150–160 米区间的损失显著大于 0–10 米区间。实际相机投影及伤害采样记录在 `docs/damage-curve-report.json`，由测试生成。[查看曲线图](damage-curve.png)；图由 `scripts/plot_damage.py` 直接读取 Godot 的实际采样生成。

普通弹均衡；扩张弹额外伤害较高、穿透较低、远距离衰减更早；穿甲弹额外伤害较少、略高初速且穿透较高。霰弹的整发威力在 7 条射线间分配，未命中的弹丸不造成伤害。守卫有独立的 AI 威力系数控制原型难度，但仍使用同一距离计算。

当前采用即时射线命中。初速参与远距离伤害保留，不模拟弹丸飞行耗时、重力下坠、风偏或穿墙。

## 价格与掉落

基础目录由 `generate_catalog.py` 生成，集中调参位于 `balance_rules.py`：

- 入门枪械保持低价，中高端枪械分段提高价格，基础弹药降价，穿甲弹保留明显溢价。
- 配件按属性变化幅度调价；整套改枪报价只计算缺少的枪体和配件，不重复收取已有物品的价格。
- 低级防具降低门槛，高级防具价格上升；背包和普通弹挂按容量选型、无防护等级；独立防弹弹挂组具有护甲等级并替代防弹衣。
- 战利品按 `drop_weight` 抽取，不再平均抽取所有稀有度。金像单箱概率约 0.43%，普通材料更常见。
- 枪械、配件、护甲、药品出售约为买价 45%，弹药约 25%，不存在买入再卖出的正向套利。
- 新存档初始资金 12,000，基础装备和补给保留；已有存档余额不被重置。破产救济维持可继续出战。

## 可重复模拟

运行 `python3 scripts/simulate_economy.py`，使用当前目录和实际箱子构成、配件池、弹药数量、掉落权重，固定随机种子进行每种路线 20,000 次模拟。完整结果在 `docs/economy-report.json`。

| 假设路线 | 毛收益中位数 | 设定消耗 | 净收益中位数 |
| --- | ---: | ---: | ---: |
| 4 箱，未搜守卫物资 | 4,868 | 45 发普通弹 + 1 急救包，1,150 | 3,718 |
| 7 箱 + 2 份守卫物资 | 12,127 | 100 发普通弹 + 2 急救包，2,400 | 9,727 |

按第一种路线的成功撤离净收益：850 的基础握把一次可以买；3,900 的入门冲锋枪约两次；11,300 的中档步枪约四次；63,850 的顶级精确步枪完整配装约十八次。初始资金、已有装备复用、直接留用搜到的配件均可缩短升级过程。全目录枪械、配件、护甲合计 834,150，几次行动无法全部买齐。

模拟假设容量足够，搜到的物品全部售出，未出售自己携带的装备，且上述收益是成功撤离的结果。模拟另列 50%、65%、80% 的假设撤离率及阵亡整套损失；低撤离率可能亏损。它们是调参场景，并非实测玩家胜率。正式平衡仍需要真机试玩、不同技术水平和更长局数的反馈。

## 验证

`test_ballistics.gd` 验证全枪全弹的距离单调性、每米损失随距离递增、150–160 米对照、近距威力、零伤害边界、初速变化和穿甲取舍；`test_combat_distance.gd` 验证实际物理射击在不同距离造成不同伤害，以及实际世界使用稀有度权重。`test_screen_damage.gd` 使用正式 Camera3D 的真实投影，验证 16:9、20:9、21:9 视野内伤害及最远校准点。其余测试覆盖报价、整套购买、三把武器、弹药守恒、触控、搜取和撤离。
