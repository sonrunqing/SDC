# 0.4.11 变卖物：48 种、8 类

本版将原有 12 种变卖物扩充为 48 种，全部重做原创 3D 模型并从实际模型渲染图标。生活物品数量最多；收藏品均为稀有及以上；高精度仪器只有 4 种，出现权重较低且价值较高。新增电子元件、医疗物资和机修工具三个分类。

**未搜索出的物品先进入未知格子绘制分支，不读取品质色。** 未知边框、扫描带、进度、旋转提示和角标均使用中性灰白；正在搜索和尚未搜索都不提前透露品质。搜索完成后，物品本身、淡色底和详细信息才显示。搜索页面详情显示已发现物品的分类、品质、重量、格子与价值。

图鉴物品浏览提供上述八类筛选和分类名称搜索。详细描述来自实际物品定义；医疗物资类的三种变卖物以及肉类罐头仍按变卖物处理，不直接治疗或恢复人物状态。

## 容器与掉落

不同容器按用途从相应分类池中抽取物资，再按品质权重选择具体物品。品质权重为普通 12、少见 6、稀有 2.5、珍稀 0.9、珍贵 0.3；这些是候选物品各自的相对权重，不能直接当作最终掉落百分比。

| 容器类型 | 变卖物候选分类 | 其他规则 |
|---|---|---|
| 机修箱 `tool` | 工业品、金属、机修工具 | 保留弹药与配件生成规则 |
| 医疗箱 `medical` | 医疗物资 | 每次物资抽取独立有 50% 概率改为野战医疗包 `medkit_field`，其余从医疗变卖物中加权选择 |
| 档案箱 `archive` | 收藏品 | 不额外生成弹药 |
| 电子箱 `electronics` | 电子元件、高精度仪器 | 按已有弹药规则处理 |
| 补给箱、武器箱、背包及其他类型 | 全部 48 种 | 各自原有的弹药、配件规则保留 |

这使贵重仪器、藏品和工业材料有对应的搜索方向。当前仍为 26 个固定室内容器，放置在 5 座可进入建筑；未增加室外散乱物资点。医疗箱的治疗用品机会单独保留，避免扩充变卖物后稀释治疗补给。

沿用 [0.4.10 容器交互](CONTAINER_GESTURES_0_4_10.md)：快速双击自动转移，单击选中后再点目标格子放置，长按拖动，并按目标格子智能选择横竖方向。携行与容器可双向操作，不增加“拿取所选”按钮；未发现物品仍不可转移。容器剩余内容、已发现位置和搜索进度继续在本局保留。

## 兼容与数据来源

原有 12 个 ID 完整保留，默认尺寸继续为 1×1，避免旧仓库位置和装备内容因本次美术更新改变尺寸：

`loot_wire`、`loot_battery`、`loot_tools`、`loot_filter`、`loot_radio`、`loot_processor`、`loot_watch`、`loot_statue`、`loot_documents`、`loot_lens`、`loot_fuel`、`loot_scrap`。

新增 36 个 ID 使用表中尺寸；没有重命名旧物品，也没有更改存档 schema。目录总条目数从 260 增至 296。本次对原有物资的数值调整为：

- 光学镜片：基准价 2,200 → 5,200，卖价 1,232 → 2,912，少见（绿）→ 稀有（蓝），单物品掉落权重 6 → 2.5。
- 机械腕表：稀有（蓝）→ 珍稀（黄），单物品掉落权重 2.5 → 0.9；价格、卖价和重量不变。

维护入口：

- `data/valuable_catalog.json`：分类、名称、尺寸、描述和定价源。
- `scripts/sync_valuable_catalog.py`：仅合并变卖物到 `data/items.json`；目录整体生成器也读取该定义。
- `scripts/item_rarity.gd`：品质名称、五档淡色和分类标签。
- `data/valuable_models.json`：48 个模型与图标的路径、三角面数、尺寸和摘要。

## 原创模型、图标与移动资源

48 个物品各有独立造型与细节，例如电缆接线端、工具箱中的批头与卡尺、腕表计时盘、压力表指针、显微镜载物台和双风扇板卡。生产 GLB 每件导出为一个合并网格，使用米制单位。全部 GLB 共 142,818 个三角面、5,569,000 字节。

可编辑 Blender 源文件在仓库根目录的 `art_source/valuables/SDC-valuables.blend`，保留各物品独立零部件、材质与可编辑文字，并按八类收纳。生成代码为 `scripts/generate_valuables.py`；使用说明见仓库根目录 `art_source/valuables/README.md`。模型和渲染图标为本项目原创，按 CC0-1.0 提供；授权说明在 `assets/valuables/LICENSE.txt`。

图标是同一批模型的正交实拍渲染，使用透明背景和统一棚光。主 PNG 为 640×640，Godot 的 `process/size_limit=320` 将移动端导入纹理限制到 320 像素；显示时保留物品比例。`.blend` 位于 Godot 工程外，避免在手机包中导入可编辑源文件。
