# 大厅、地图与资源（0.3.0）

## 界面结构

应用首先进入人物大厅，展示当前装备的完整人物模型。首页保留资金、当前武器与系统入口，详细属性留在装备系统中。底部提供角色装备、仓库、商店、改枪和图鉴；右下角“开始行动”进入地图选择。

出战流程为：大厅 → 行动区域 → 出战整备 → 战局。行动区域显示真正的 3D 港区，可旋转、缩放，也可点击分区放大。当前地图为灰港工业港，有南港货闸、东侧维修区、西侧铁路三个实际出生入口。选择入口后进入独立整备页，确认携行与弹药再出战。

商店先显示六个大类：枪械、枪械配件、防护装备、背包与弹挂、弹药、医疗。大类内再按枪种、部位或口径筛选，随后选择装备卡片进行交易。仓库使用物品卡片和独立详情区；模型缩略图为实际装备渲染，共 256 张，避免为每张卡片运行一个实时 3D 视口。

改枪仍为独立的完整工作台，实时组装、报价和整套购买流程可用。返回按钮根据所在层级返回分类、大厅或选图，战局结算后返回人物大厅。

## 人物

`generate_operator.py` 使用 Blender 生成原创低多边形人物和 36 件独立护具/容器模型，共 37 个 GLB。头盔、面罩、防弹衣、弹挂甲和背包按当前物品 ID 装到人物上；三把枪使用与改枪台相同的 WeaponAssembly，安装配件也会显示。大厅与出战整备可以转动人物，观察背包和背负武器。战局玩家也使用该人物及实际护具模型。

原型人物为原创开发美术，具有衣物分段、口袋、膝部防护、MOLLE、头盔接口、面罩及背包细节；尚无完整骨骼动作和写实角色材质。角色呼吸、持枪姿态与装备展示已经接入，不能等同于商业游戏的正式美术质量。

## 港区

| 项目 | 当前内容 |
| --- | --- |
| 地图尺寸 | 160 × 180 米 |
| 原尺寸 | 48 × 52 米 |
| 面积扩大 | 11.538 倍 |
| 已布置模型 | 97 种，261 个场景实例 |
| 区域 | 南港、铁路仓储、集装箱码头、海关仓库、油罐区、能源站、北侧撤离区 |
| 物资点 / 守卫 | 27 / 17 |
| 可选入口 | 3 |
| 单局时限 | 15 分钟 |

`data/harbor_layout.json` 为场景和地图预览共用布局。道路、建筑、集装箱、管道、机械、车辆、太阳能设施和照明按此布局生成；地图扩大同时改变碰撞、寻路、物资点、出生点、镜头跟随边界和撤离距离。地图不是把旧预览图片放大。

场景按模型和 32 米空间分块进行 MultiMesh 批处理；战局远处区块有显示距离，远处未警戒守卫暂停路径更新。导航障碍按矩形范围直接栅格化，避免每个网格逐个扫描全部模型。预览与战局使用相同网格资源，预览不添加物理碰撞。

所有入口和物资点的可达路线、远端建筑的实际射线碰撞、扩大后的边界与出生位置均有测试。实际安卓帧率和触控舒适度仍需真机验证。

## 重建与验证

1. Godot 编辑器导入下载模型后，运行 `tests/inspect_environment.gd` 生成模型尺寸与三角形元数据。
2. `python3 scripts/generate_harbor.py` 重建布局。
3. `blender --background --python scripts/generate_operator.py` 重建人物与护具。
4. 使用实际显示或 Xvfb 执行 `tests/render_item_icons.gd` 重建 256 张物品图片，然后让 Godot 导入 PNG。
5. `/workspace/setup/test-game.sh` 运行包括新大厅、商店层级、换装同步、入口和地图通路在内的完整验证。
