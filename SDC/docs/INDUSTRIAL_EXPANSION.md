## 编辑与重建

- Blender 工程：`D:/aa/SDC-tools/blender/SDC_Industrial_Expansion.blend`。
  - `ExpansionLibrary`：隐藏原件与优化组件库；`RAW_NEXT_*` 是本批原件集合。
  - `HarborExpansion`：584 个实际地图模型的摆放快照。
  - `Expansion_UCX_CollisionGuides`：隐藏的碰撞参考线框。
  - 原 `ModuleLibrary`、`HarborAssembly` 保留。
- 原始第一批作者文件 `SDC_Industrial_Authoring.blend` 保留。
- 原地图数据及脚本备份：`D:/aa/SDC-tools/backups/industrial-expansion-20261017/`。

流程：

1. Blender 内执行 `scripts/prepare_industrial_expansion.py`，导出优化 GLB。
   使用当前场景与当前选择过滤，避免将其他场景误导出到单个模块中。
2. 导出的 `EXPANSION_EXPORTS` 几何边界写入 `data/industrial_expansion_exports.json`。
3. 运行 `python scripts/build_industrial_catalog.py`，合并两批目录，生成碰撞数据和 26 个组件场景。
4. 运行 `python scripts/generate_harbor.py`；会依次调用 `industrial_layout.py` 和
   `industrial_expansion_layout.py`，重建实际地图。
5. Blender 快照脚本为 `D:/aa/SDC-tools/blender/assemble_industrial_expansion.py`。
   通过 MCP 传入最新布局和资源数据后运行；Blender 移动对象不会自动反写游戏布局。
