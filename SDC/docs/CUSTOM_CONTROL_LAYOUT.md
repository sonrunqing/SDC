# 自定义操作按键

入口：大厅或战局设置 → 操控 → 自定义操作按键。

## 玩家可调整的内容

- 选择方案 1 / 2 / 3，各自独立保存。
- 拖动移动摇杆、瞄准摇杆、开火、换弹、搜索/拾取、治疗、三把武器和菜单的位置。
- 单独调整每个按键的大小（65%–180%）与透明度（20%–100%），并用方向按钮微调。
- 隐藏不需要的辅助按键，仍保留移动、瞄准、开火与菜单，避免无法操作或重新进入设置。
- 重置所选按键，或恢复当前方案的默认布局。
- 保存并应用，或取消本次草稿。离开游戏后方案仍保存在本机设置中，不改动游戏存档和装备。

## 编辑和战局的一致性

`control_layout.gd` 是按键几何的共同来源。位置使用显示安全区内的归一化坐标，大小与形状共用于
战局绘制、实际点击范围和编辑预览。预览按真实屏幕宽高比缩放，不写入编辑窗口的像素位置。
移动、瞄准、开火仍有独立的手指归属；手指从摇杆划到开火区不会转为开火。
隐藏按键不响应触摸。动作按钮在未滑动的抬指时触发，开火为按住触发。

编辑预览不会产生游戏射击、治疗、切枪或菜单操作。战局中打开布局编辑时，保存当前暂停状态并冻结场景；
保存或取消后恢复原暂停状态，回到原来的设置界面。Android 系统返回取消未保存的草稿；打开选择列表时，返回先关闭列表。

## 边界与保存

- 所有实际按键范围限制在安全区内；不同屏幕比例和界面缩放会重新换算位置。
- 按键重叠时在编辑器标红并禁用保存，避免移动区与开火区交叠造成误操作。
- 若保存的布局在另一屏幕比例下出现重叠，战局临时使用默认布局并提示重新调整；保留原方案供编辑。
- 保存写入 `user://settings.cfg` 的 `controls` 节，包括 active、version 和三个 profiles。
- 原设置文件没有 controls 节时使用默认三指布局，既有整体大小/透明度作为初始值。
- 保存失败时恢复内存中的原方案并显示错误，不误报保存成功。

## 源码

| 文件 | 职责 |
| --- | --- |
| `control_layout.gd` | 布局默认值、清洗、屏幕换算、命中与重叠检查 |
| `virtual_controls.gd` | 按保存方案绘制和接收实际战局输入，预览模式不接收游戏操作 |
| `ui_control_layout_canvas.gd` | 等比预览、选中和拖动 |
| `ui_control_layout.gd` | 编辑工具、草稿、取消/保存、场景冻结与恢复 |
| `app_settings.gd` | 三方案的持久化、切换和布局变更信号 |
| `ui_settings.gd`、`main.gd` | 大厅/战局入口与返回处理 |

本次没有新增或运行测试。Android 导出、脚本编译与签名核对属于交付过程，不能等同于真机触摸验证。
