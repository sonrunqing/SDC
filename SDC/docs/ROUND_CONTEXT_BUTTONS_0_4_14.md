# 0.4.14：小齿轮菜单与按物资距离出现的圆形搜索键

本版包含 [0.4.13 手机十字准星与清晰物品分层](MOBILE_RETICLE_0_4_13.md)，并落实后续两条按钮反馈。0.4.13 是此轮中间构建，最终交付以 0.4.14 记录为准。

## 小齿轮菜单

局内原“菜单”矩形文字按钮替换为小圆形齿轮，不显示长文字。默认可见直径约28个设计单位，居中的8齿齿轮由矢量绘制；其周围保留直径44的透明圆形触摸目标。只在按压时有反馈，无待机闪烁或变色。原有自定义位置、大小和透明度仍由同一布局系统管理。

## 近距离圆形搜索键

原“搜索 / 拾取”矩形改成圆形放大镜和“搜索”字样，默认可见直径约56、触摸直径64。只有附近存在尚未取空、可以直接接触的物资容器时显示并响应；布局编辑器始终展示以便调整位置。

可接触判断沿用战局权威逻辑：最近物资约2.25米内，并通过原有距离和物理视线检查；隔墙、远处和已取空容器不提供可执行目标。点击打开逐件搜索页面，不自动把全部物资塞进背包。

每个物理帧同步交互目标变化给 HUD，离开或更换目标时取消当前搜索键按压。按下时绑定容器索引，抬指时携带该索引，世界再次查找当前最近可接触容器；若不一致则忽略。因此目标变化、HUD更新和松手的先后顺序不会让旧触点在另一个箱子上触发。

## 输入与几何

`control_layout.gd` 将菜单和搜索标记为圆形，用同一圆形包含判断处理按下、抬指、碰撞和自定义编辑。`virtual_controls.gd` 明确区分移动/瞄准/开火三个独立所有者与菜单/搜索等松手动作，避免“圆形就被当作摇杆”导致菜单或搜索失效。

控件隐藏、失去物资目标、模态页面、后台及布局变化均保留原有手势取消流程。没有添加键鼠输入或触摸转鼠标回退。
