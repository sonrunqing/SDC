# SDC 0.4.7

Godot 4.6.3 / GDScript / Android ARM64 单机 PvE 搜打撤原型。使用斜俯视 3D 工业港场景，包含人物大厅、地图预览、装备仓库、商店、改枪、搜刮、交战和撤离。

用 Godot 4.6.3 打开本目录的 `project.godot`，按 F5 运行。工程内已包含运行所需 GLB、图标、贴图、字体和音效，不需要重新生成模型。

## 手机操作与页面

- 移动、瞄准与开火独立：左摇杆移动，右摇杆改变朝向，左上按钮开火；另有换弹、搜索、治疗和武器切换。
- 点击大厅的开始行动打开地图预览，在预览页再次点击开始行动进入战局。出击条件不足时显示原因。
- 地图预览支持单指平移、双指缩放与旋转。人物和枪械预览也直接使用原始触摸手势。
- 装备与仓库为同一页面。仓库 500 格，背包与弹挂按各自区块显示；支持长按拖动、点击选择后放置、双击快捷转移和智能旋转。
- 普通弹挂只提供储物，可与防弹衣、背包同时穿戴。新增防弹弹挂独立商店分组，与防弹衣互斥，可配背包；装备页的防弹衣栏淡色显示同一件结合体。容器替换失败应完整恢复原状态。
- 改枪显示后坐控制、水平后坐控制、人机功效、射程、击发威力、射速和精准度。数值方向统一为越高越好。
- 设置包含帧率、3D 分辨率、画质、音量、操控大小、死区、灵敏度、安全边距与界面缩放。
- 设置 → 操控 → 自定义操作按键，可调整 10 个操作控件的位置、大小和透明度，保存 3 套独立方案；支持辅助按键显隐、单键重置与整套重置。
- 0.4.6 修复普通触摸短按使大厅按钮锁在按下状态的问题，并统一仓库、列表和布局编辑器的输入来源处理。
- 0.4.7 关闭全部指针模拟并删除键鼠操作代码，设置选择器、滑条、开关、搜索和数量输入均直接响应手机触摸；仓库单次点选可查看全部 260 件物品的实际详情。

每局十五分钟，在北侧撤离区停留五秒即可带出物资。成功撤离后保留装备和战利品；失败会损失携带物品，仓库库存保留。

## 角色、装备与地图

主武器、副武器和手枪各自保留配件、弹种及装填数量，同型号弹药共享备弹。配件选择先形成草案，确认购买缺件并装备时再一次结算，不应在预览草案期间扣费或改变库存。

枪体和配件采用独立模型与 Socket 连接，大厅、改枪预览和战局共用组装。人物按实际穿戴显示装备。工业港由模块化建筑、墙体、平台、楼梯、栈道及道具组成，包含建筑入口、碰撞、搜刮点和守卫。地图预览与战局共用布局。

## 代码入口

| 路径 | 职责 |
| --- | --- |
| `scripts/main.gd` | 页面、出击、HUD、反馈与导航 |
| `scripts/game_state.gd` | 装备、库存、交易、行动物品与持久化 |
| `scripts/inventory_state.gd`、`inventory_grid.gd` | 物品转移事务、格子与摆放 |
| `scripts/ui_inventory.gd`、`ui_inventory_grid.gd` | 仓库装备界面与触摸手势 |
| `scripts/virtual_controls.gd`、`raid_world.gd` | 三指输入、移动、射击和战局 |
| `scripts/map_preview.gd`、`harbor_map.gd` | 地图预览、运行场景和碰撞 |
| `scripts/catalog.gd`、`data/items.json` | 物品、兼容关系、性能和目录 |
| `scripts/weapon_assembly.gd` | 独立枪械组件拼装 |
| `scripts/app_settings.gd`、`ui_settings.gd` | 参数持久化与设置页面 |

存档位于 Godot `user://extraction_save_v1.json`，当前 schema 为 3，保留旧版本迁移逻辑。源码、数据和资源来源说明均纳入 Git；`.godot/` 是可重新导入的编辑器缓存，不上传。

## Android 更新

当前版本 **0.4.7 / versionCode 14**。从固定签名的 0.4.3 起，保持包名、同一密钥并递增版本，按覆盖更新交付。原云端 0.3.0 是另一签名，用户曾批准在迁移至 0.4.3 时进行一次清空重装；之后不应继续要求卸载。密钥与两份备份保存在项目外，禁止重新创建密钥替代。

Android 导出需要本机 SDK、JDK 和对应 Godot 模板；现有 Windows 构建入口在 `D:/aa/SDC-tools/build-android.ps1`，配置和签名检查保存在该工具目录。查看和审查代码不需要签名密钥，也不依赖旧云端 `/workspace/setup/` 脚本。
