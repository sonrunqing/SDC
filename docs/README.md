# SDC 0.3.0

Godot 4.6.3 / GDScript / Android ARM64。单机 PvE 可玩原型，采用斜俯视 3D 工业货场，包含搜刮、交战、撤离、仓库出售、购买装备与实时改枪。

打开 `project.godot` 按 F5 进入人物大厅。底部进入角色装备、仓库、商店、改枪和图鉴；开始行动后依次进入地图选择、出战整备和战局。新存档包含基础装备、180 发弹药、医疗补给和 12,000 游戏币。手机左摇杆移动，右摇杆瞄准射击，独立按钮换弹、搜索、治疗和切换三把武器；电脑使用 WASD、鼠标、R/F/E 和 1/2/3。游戏画面不显示教学文字或流程口号。

每局十五分钟，搜索物资箱需要短暂停留；在北侧撤离区停留五秒即可带出物资。成功后物资进入仓库，可售出或留下。阵亡、超时或战局中退出会失去携带装备与本局战利品，仓库库存保留。进度自动存档。

## 大厅与地图

大厅人物按实际装备显示头盔、护甲、背包和枪械，可旋转查看。商店先选六个大类，再进入枪种、口径或部位子列表；256 张物品卡片使用实际模型渲染图。

灰港工业港现为 160 × 180 米，面积扩大 11.538 倍，使用 97 种场景模型，共 261 个实例、27 个物资点和 17 名守卫。三处出生入口均可到达北侧撤离区；地图选择显示同一真实场景，可旋转、缩放和按区域放大。详见 [界面与地图说明](docs/FRONTEND_AND_MAP.md)。

## 实时改枪与三武器

在改枪页选择任意枪械和兼容配件，完整枪体及装上的部件会实时显示，可以旋转、缩放、卸下和替换。24 个枪体、145 个配件以及 62 个原厂部件各为独立 GLB；同一拼装组件也用于战局持枪、背枪。

选择配件只是草案。界面显示已有数量、缺件与总价；确认“购买缺件并装备”后，一次支付缺少的枪体和配件，并把组装完成的枪放入指定武器栏。支持主武器、副武器和手枪，每把枪独立保存配件、弹种及弹匣。相同弹药型号共用备弹，携弹数量在出击前设置。

枪下方为单条 0–100 综合性能条。实际伤害包含枪械威力、弹药额外伤害、初速影响的加速距离衰减和护甲穿透，屏幕内衰减较小，参考枪弹从近距约 22.8 到 21:9 最远可见边缘 20.5；屏幕以外继续按曲线加快衰减，内部伤害参数不在界面直接显示。价格与战利品权重经过场景模拟，详见 [伤害与经济调参](docs/BALLISTICS_AND_ECONOMY.md)。

## 开发与验证

当前云端工作区已配置 Godot、Android SDK、JDK、Blender 和 Blender MCP。本机编辑器启动：`bash /workspace/setup/open-godot.sh`；全套验证：`bash /workspace/setup/test-game.sh`；安卓导出：`bash /workspace/setup/build-android.sh`。

APK 输出为 `/workspace/builds/android/sdc-v0.3.0.apk`，Android 7.0+、ARM64，开发签名。下载源码后可用 Godot 4.6.3 打开；重新导出时配置本机 JDK、SDK 和对应导出模板。

目录重建：`python3 scripts/generate_catalog.py --require-models`；经济模拟：`python3 scripts/simulate_economy.py`；原创模型重建使用 Blender 执行 `scripts/generate_models.py`。素材和字体授权见 [来源说明](THIRD_PARTY_ASSETS.md)。

这是离线单人原型，尚无多人服务器、账号或联网经济。枪械是原创低多边形开发美术；人物和 36 件穿戴装备已独立建模，仍属于原创低多边形开发美术。背包按重量计算，尚无拖放格子、逐实例耐久维修或完整骨骼动作。射击用物理射线，初速影响远距伤害，不模拟弹丸飞行与下坠。安卓真机帧率、触控手感及音频尚需实机验证。出售所得仅为游戏内货币。
